### 2. 本人身份文件

首次買幣通常需要完成 KYC 身份認證。官方說明顯示，未完成身份認證的帳戶可能無法進行買賣幣、充值、提現或資金劃轉等操作。

常見流程包括：

- 填寫個人基本資料
- 提交政府核發的身份文件
- 進行自拍或臉部驗證
- 等待平台完成審核

認證資料必須與付款帳戶或銀行帳戶名稱一致，尤其是使用銀行轉帳或 ACH 等方式時。OKX 的 ACH 說明也特別提醒，平台帳戶姓名需要與連結的銀行帳戶姓名一致。

### 3. 可用的付款方式

你可以先確認自己打算使用哪一種方式：

- 銀行轉帳：通常適合較大金額或希望直接使用法幣餘額的人
- 信用卡或簽帳金融卡：操作較快，但費用可能因支付服務商而不同
- C2C：由平台上的其他商家或用戶提供報價，付款方式選擇較多
- 從其他交易所轉入 USDT 或其他資產：適合已有其他平台帳戶的人

支付選項不是全球統一。美國合資格地區的已驗證用戶可能看到 ACH 銀行轉帳，但官方明確表示，ACH 僅適用於符合資格的美國州別與已連結銀行帳戶的用戶。

## 買 BTC、ETH 和 USDT 有什麼差別？

### BTC：最常被新手接觸的主流資產

Bitcoin，也就是 BTC，通常是新手最先研究的虛擬貨幣。購買時可以選擇輸入法幣金額，也可以直接輸入想購買的 BTC 數量。

BTC 價格較高，不代表你必須購買一整枚。多數平台支援小數量交易，使用者可以按照預算購買部分 BTC。

### ETH：與智能合約和鏈上應用相關

Ethereum，也就是 ETH，除了作為交易資產，也常被用於支付以太坊網絡上的 Gas 費。若未來要使用某些 Web3 應用、NFT 或去中心化交易功能，ETH 可能會出現在資產配置中。

但 ETH 的價格與網絡費用都會變動，不能只因為「用途很多」就直接判定適合所有人。

### USDT：常見的穩定幣交易媒介

USDT 通常被用作美元計價的穩定幣，很多交易對會以 USDT 作為報價單位。常見做法是先購買 USDT，再用 USDT 在現貨市場購買 BTC、ETH 或其他資產。OKX 的官方教學也將「先取得 USDT，再進行幣幣交易」列為常見交易流程。

不過，USDT 不是銀行存款，也不是完全沒有風險的現金替代品。購買前要確認使用的網絡、充值地址及提現網絡是否一致。

### Maker 和 Taker 是什麼？

- **Maker，掛單**：你的訂單先掛在訂單簿上，等待其他人撮合。

對只買一次 BTC 的新手來說，VIP 等級通常不是重點。先確認實際到帳數量、支付費用和提現規則，比研究最高 VIP 等級更有用。

## 怎麼買虛擬貨幣比較不容易出錯？

### 先用小額測試

第一次買幣不必一次投入大筆資金。可以先用自己能承受損失的小額測試完整流程，包括：

- 註冊和 KYC
- 入金
- 買入資產
- 查看餘額
- 提現或轉帳
- 確認網絡和地址

這樣做的價值在於，你會先熟悉操作，而不是等到大額轉帳時才發現自己選錯網絡。

### 不要只看買入價格

平台可能顯示一個看起來很漂亮的即時價格，但你真正支付的成本可能還包括：

- 買幣服務費
- 支付處理費
- 匯率差
- 點差
- 交易手續費
- 提現手續費
- 鏈上 Gas 費

下單前看「預計收到數量」和「實際支付金額」，不要只盯著 BTC 或 ETH 的報價數字。

### 確認幣種與網絡

轉帳時，幣種名稱相同不代表網絡相同。例如 USDT 可能存在於不同區塊鏈網絡。充值和提現時，發送網絡與接收網絡必須匹配，否則資產可能延遲甚至無法找回。

如果是透過 Web3 錢包購買代幣，還要確認代幣的合約地址與所屬網絡。OKX 官方也提醒，不同網絡可能存在同名代幣，甚至有假代幣，交易前應核對合約地址。

### 不要一開始就碰槓桿和合約

「虛擬貨幣怎麼買」和「虛擬貨幣怎麼做合約」是兩個完全不同的問題。

現貨交易是用資金購買資產，價格下跌時資產價值會減少，但不會因槓桿機制直接產生強制平倉。合約交易則涉及保證金、資金費率、槓桿和強制平倉，風險結構完全不同。

對剛完成第一次買幣的人來說，先理解現貨買入、賣出、充值和提現，再考慮其他產品，會比較容易掌握實際風險。

## 買到虛擬貨幣後，資產放在哪裡？

買入後，資產通常會顯示在交易所帳戶內。這種方式操作方便，適合需要頻繁交易或還在熟悉市場的人。

另一種方式是轉到自主管理錢包。自主管理錢包的私鑰或助記詞由自己保管，平台無法替你重設。如果助記詞遺失，或被他人取得，資產可能無法追回。

可以按照使用情境選擇：

| 使用情境 | 較適合的方式 |
| --- | --- |
| 剛開始學習買幣 | 先留在交易所帳戶，熟悉基本操作 |
| 需要頻繁買賣 | 保留交易所內的交易資金 |
| 長期持有且熟悉錢包 | 研究硬體錢包或自主管理錢包 |
| 需要使用 DeFi 或鏈上應用 | 使用 Web3 錢包，但要自行確認網絡與合約 |
| 不熟悉助記詞管理 | 不要急著轉出，先學會備份與恢復流程 |

無論資產放在哪裡，都不要把密碼、驗證碼、私鑰或助記詞交給任何人。平台客服不會要求你提供錢包助記詞。

## 常見問題：虛擬貨幣怎麼買？

### 沒有很多錢，可以買虛擬貨幣嗎？

通常可以。BTC、ETH 等資產支援購買部分數量，不需要一次買入整枚。最低金額、最小下單數量和支付限額則要看幣種、交易對和付款方式。

### 可以直接用信用卡買 BTC 嗎？

部分地區和支付服務商支援信用卡或簽帳金融卡。你需要在買幣頁面確認卡片選項是否可用，並留意發卡銀行可能收取海外交易費、現金預借費或額外處理費。

### C2C 買幣安全嗎？

C2C 使用平台托管與訂單流程交易會比私下交易更容易追蹤，但不代表完全沒有風險。付款時要按照訂單資訊操作，不要私下轉帳，也不要在未確認資產放行前取消訂單。

### 為什麼買到的數量比預期少？

常見原因包括支付費用、價差、交易手續費或匯率差。部分卡片買幣服務的報價也可能與現貨市場價格不同，最終應以確認頁面顯示的「支付金額」和「收到數量」為準。

### 買完後可以立刻提現嗎？

不一定。某些支付方式可能有短暫持有期或提現限制，尤其是銀行轉帳或卡片充值。OKX 的 ACH 說明也指出，資產可能可以先用於交易，但提現會受到短暫限制。
